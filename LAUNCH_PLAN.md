# RetroKit Launch Plan

## Before publishing

- Confirm the final domain in `lib/site.ts` and verify that `/robots.txt` and `/sitemap.xml` return absolute URLs.
- Publish a release for each npm package and verify that the homepage, repository, README, keywords, and images render correctly on npm.
- Prepare three destination links: the landing page, documentation, and showcase.
- Capture a showcase screenshot for launch posts and social previews.

## Recommended launch sequence

### Product Hunt

**Title:** RetroKit — Windows 3.1 and System 7 UI kits

Use a short description, three screenshots, and a direct link to `/showcase`. Highlight the free React, Tailwind CSS, and Web Components packages.

### Hacker News / Show HN

Explain the problem RetroKit solves, link to the repository, and ask for technical feedback. Keep the post informative rather than overly promotional.

### Reddit

Adapt the post for `r/webdev` and `r/reactjs`. Include a visible demo and one specific question for the community.

### Awesome lists

Submit RetroKit to relevant lists for Tailwind CSS, React UI, Web Components, and retro computing. Follow each repository's contribution rules and formatting requirements.

## Launch copy

> RetroKit is a free set of Windows 3.1 and Mac System 7 inspired UI kits for React, Tailwind CSS, and Web Components. It includes reusable buttons, windows, menus, dialogs, and form controls with accessible focus states and ready-to-copy examples.

## After publishing

- Reply to comments with deep links to the relevant documentation instead of only linking to the homepage.
- Track which channels generate visits and npm installs with UTM parameters in campaign links.
- Update the README and landing page with recurring questions and feedback.
- Record launch results, including referral traffic, npm downloads, GitHub stars, and showcase engagement.

## External setup still required

- Verify the domain in Google Search Console.
- Verify the domain in Bing Webmaster Tools.
- Submit the sitemap to both services.
- Execute the launch and measure the results.
